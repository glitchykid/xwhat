X What устанавливается в Program Files. .NET и PresentMon уже входят в приложение.

По умолчанию устанавливаются RTSS для вывода поверх игр и подписанный PawnIO для доступных температур CPU. Уже установленные компоненты сохраняются. Установщик загружает отсутствующие компоненты с официальных серверов и проверяет SHA-256. Для этой загрузки нужен интернет.

Вы можете отключить RTSS или PawnIO на странице выбора компонентов. Устанавливая выбранные компоненты, вы соглашаетесь с их лицензиями:
RTSS: https://www.guru3d.com/page/rivatuner-rtss-homepage/
PawnIO: https://pawnio.eu/ и https://github.com/namazso/PawnIO

Для FPS и датчиков создаётся защищённая задача Windows, запускающая только установленный XWhat.exe с доступными повышенными правами. Пароль не сохраняется. Пользователь получает право запуска этой задачи, но не изменения её программы. Автозапуск остаётся отдельной настройкой X What.

Текущая учётная запись получает доступ к журналам производительности для PresentMon. Для стандартной учётной записи может потребоваться новый вход в Windows; установщик сообщит об этом.

После установки запустите X What и перезапустите игру, чтобы RTSS подключился к её графическому процессу. Программа будет сама запускать установленный RTSS. Доступность оверлея зависит от поддержки игры.

При удалении X What удаляется его задача запуска. RTSS, PawnIO, сохранённые настройки и право чтения журналов производительности сохраняются: ими могут пользоваться другие программы. Компоненты можно отдельно удалить через «Установленные приложения» Windows.
